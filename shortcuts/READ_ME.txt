CREASEIQ - WEB APP SHORTCUTS

1. Extract this ZIP into a folder.
2. On Windows, double-click Open_CreaseIQ.url to open the app in your default browser.
3. On macOS or Linux, open Open_CreaseIQ.html in a web browser. It redirects to the app automatically.

App: https://creaseiq.streamlit.app/

An internet connection is required. No Python installation or local setup is needed.
These shortcuts open the hosted app; they do not contain the application or an API key.
