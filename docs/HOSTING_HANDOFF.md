## Check a deployment

1. Open the public app in a fresh browser tab after the repository update.
2. Confirm **CREASEIQ** is shown in the sidebar and version **3.1.0** below the navigation.
3. Home explains the name and the workflow. Load the RCB example and prepare a brief in Local evidence mode.
4. Open Project guide and download the PDF guide and complete project ZIP.
5. Keep any DeepSeek key in the existing private hosting Secrets. The rename does not require a new key or a paid service.

Local automated and browser results do not certify a successful cloud rebuild or live provider quality.

## Saved local work

Export private journals before any hosting change. The app uses `CREASEIQ_RUNTIME_DIR` when set, otherwise the local `.runtime` folder. At first use of the renamed store, exactly one compatible earlier SQLite store in the same folder is adopted without deleting it. If several compatible stores exist, they are left untouched instead of being merged. Hosting storage is still temporary and session-scoped; it is not an authenticated team account system.
